关于这个图鉴

学习入口，也是一套观察方法

面向美术初学者与 AI 创作爱好者，用作品理解风格，用可观察的特征辅助创作。

内容怎样组织

风格指南说明共性、变化和边界；参考案例保留具体作品的逐图观察；视觉特征把两者连接到创作提示词。分类与题材各自独立，视觉相似不作为历史归属的证据。

来源与作品

参考作品保留完整画幅、署名与出处。无法确认作者、题名或媒介时明确注明；“油画般”“版画感”等描述仅指可见效果。背景资料与作品来源分别标注。公开可见不等于作品获开放许可；版权仍归相应权利人，商业复用前请向来源方核对。

新增与更正

网站代码、公开的风格指南、案例和分类词表统一在独立 GitHub 仓库维护。每条内容有稳定标识，新增条目后自动进入目录与检索；加入人物路线需同时登记学习路线。发现出处错误或希望移除图片，可以通过仓库 Issue 提交对应页面与依据。

如何理解生成的提示词

提示词由浏览器根据勾选项组装，不会生成或保存图片，也不会自动读取原图。它是一份可修改的创作描述，不保证任何生成工具都能完全执行。人物、建筑和道具以你的原图为准，不从参考作品自动加入。
