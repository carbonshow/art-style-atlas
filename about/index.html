About this atlas

A starting point for learning and a method of observation

For art beginners and AI image creators: understand styles through artworks and use observable features to support creative work.

How the content is organized

Style guides explain shared characteristics, variations, and boundaries. Reference cases retain observations on individual images. Visual features connect both to the prompt builder. Classification and subject matter are independent; visual resemblance is not evidence of historical affiliation.

Sources and artworks

Reference works retain their full image area, credits, and sources. Unconfirmed authorship, titles, or media are explicitly noted; descriptions such as “oil-painting-like” or “printmaking-like” refer only to visible effects. Background references and artwork sources are identified separately. Public visibility does not imply an open license; copyright remains with the respective rights holders. Check with the source before commercial reuse.

Additions and corrections

The website code, public guides, cases, and classification vocabulary are maintained in one dedicated GitHub repository. Each entry has a stable identifier; new entries automatically appear in the catalog and search. Adding an entry to the figure-learning route also requires updating that route. To report an incorrect source or request image removal, submit the page and supporting information through a repository issue.

Understanding the assembled prompt

The browser assembles a prompt from your selections. It does not generate or save images, or automatically read the source image. The result is an editable creative description, not a guarantee that a generation tool will follow every instruction. People, buildings, and props come from your source image; they are not automatically added from the reference work.
