人物画风入门

同样画人物，观察八种选择

这些方向并非同一层级的艺术分类。沿着作品观察各自的形、线、色，再决定你想迁移什么。

01

John Singer Sargent

笔触写实肖像

把形体画准，把笔触留下来。用明暗关系建立人物，再以松动的色块表达衣料与环境。

观察题：先眯眼看：人物的亮面能否从环境中读出来？

读懂特点，再选取特征 →
02

Alphonse Mucha

新艺术

流动的轮廓把人物、衣褶与装饰组织在一起。先看线的节奏，再看画面怎样成为一个整体。

观察题：人物外轮廓是否与衣褶、装饰形成连贯曲线？

读懂特点，再选取特征 →
03

Tamara de Lempicka

装饰艺术

把身体与衣料看作精确而有力的体块。几何化的转折、利落边缘和光泽让人物显得摩登。

观察题：衣褶是否像有棱面的立体结构？

读懂特点，再选取特征 →
04

Egon Schiele

表现主义人物

形体不只记录外貌，也表达心理状态。折转的轮廓、不均匀的颜色和留白让情绪变得可见。

观察题：轮廓是否在关节和转折处突然收紧或折断？

读懂特点，再选取特征 →
05

Uemura Shōen

日本画人物

用精炼的轮廓、节制的设色和姿态传达神韵。少量线条也能表达衣料、动作与人物的精神。

观察题：面部细节是否节制，姿态是否承担了更多表达？

读懂特点，再选取特征 →
06

Moebius

幻想漫画线描

清楚的轮廓配上有选择的细节，让陌生世界显得可信。人物设计与空间想象可以由精密线描承载。

观察题：大轮廓是否先于细小纹理被读到？

读懂特点，再选取特征 →
07

Mary Blair

世纪中叶现代主义插画

大胆色彩与简洁形状共同讲故事。人物可以很小，画面依然通过形状、比例和冷暖让情绪一目了然。

观察题：缩小图片后，大色块是否仍能传达画面感受？

读懂特点，再选取特征 →
08

Malika Favre

极简人物插画

只留下不可替代的形状。轮廓、负空间和少量颜色同时承担人物识别、光影与视觉趣味。

观察题：去掉一条线或一个色块后，人物还能否被认出？

做一次自己的比较

  • 先任选一页，不看风格名称，写下三个看得见的特点。
  • 再对照页内说明，把“好看、精致、有感觉”换成具体的形状、线条和颜色。
  • 选择自己原图中适合迁移的特点，进入提示词页面，删去不需要的特征并填写本次目标。
  • 用同一主体比较两种不同描述，记录哪些变化来自线条、色彩或空间，而不是题材。
