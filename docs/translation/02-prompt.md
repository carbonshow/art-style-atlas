# Shared translation brief

Audience: art beginners and AI image creators. Use precise established art terminology in clear, natural English; no literary embellishment or omissions. Preserve every assertion, restriction, negative, number, proper name, visual judgment and uncertainty. Never turn a visual resemblance into attribution or verified technique. Both languages must convey the same facts. Existing English names and prompt clauses also need review.

Convert human-readable source fields into {"zh": original Chinese, "en": faithful English}. Keep structural IDs, types, tags/aliases, filenames, URLs, dates, hashes, numeric values, facet/group values and relations[].relationship unchanged. name should become bilingual; preserve english_name as a legacy alias. Translate label/explanation/evidence on features; preserve and review existing feature.zh/feature.en, avoid.zh/en, legacy_prompts.zh/en and motion_prompts.zh/en as prompt-language pairs. Translate references' attribution status codes into readable bilingual explanations, without claiming new facts. Artwork metadata shown to readers, credit, source titles, descriptions, palette names all need bilingual display values. Do not convert technical metadata not displayed to readers.

Never overwrite examples[].execution_prompt (actual historical text). Add execution_prompt_reading={zh,en} with its translation for reading, preserving the actual text separately. Retain original artwork inscriptions and original titles as explicit originals where needed. Translations of titles not verified in a museum source must not be represented as official titles.

Terminology conventions:
新艺术 = Art Nouveau; 装饰艺术 = Art Deco; 表现主义 = Expressionism; 日本画 = Nihonga (not all Japanese painting); 浮世绘 = ukiyo-e; 浮世绘风 = ukiyo-e-inspired; 武者绘 = musha-e (warrior prints); 工艺美术 = Arts and Crafts; 世纪中叶现代主义 = mid-century modern; 笔触 = brushwork; 肌理 = texture; 厚涂 = impasto only for an actual technique, impasto-like texture when only an appearance; 排线 = hatching; 轮廓 = contour; 剪影 = silhouette; 留白 = open/blank space according to context, negative space only when describing shape relationships; 空气透视 = atmospheric perspective; 缩短透视 = foreshortening; 有限配色 = limited palette; 不透明干刷 = opaque dry-brush marks; 版画质感 = printmaking-like texture (not an assertion of printmaking technique); 未核实 = unverified; 视觉借鉴 = visual influence / visual borrowing, never verified historical classification; 原作 = original artwork; 复现图 = reproduction; AI改绘 = AI reinterpretation; 金箔效果 = gold-leaf effect (do not claim actual gold leaf).

Author and work names: use existing original-language proper names and linked collection records. Avoid fabricating official English translations. Site descriptions of user-provided illustrations are descriptive titles, not verified artwork titles.

Workflow: read each full entry; draft bilingual fields; review paragraph by paragraph against source; revise all issues; read English alone; record concrete findings in your assigned audit file. Do not claim an independent human review. Do not edit media, scripts, templates or unrelated files. No publishing, git commits or network uploads.
