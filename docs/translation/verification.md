## 浏览器实测

在本地回环地址使用实际浏览器检查。桌面视口 1440×1000 和手机视口 390×844 均覆盖中英文首页、风格库、学习总览、人物路线、词典、创作页、关于页、指南、案例及 404。额外检查 AS-007、AS-009、AS-010 的较长英文标题，以及 320×700 窄屏首页。48 次页面/语言/视口组合检查未发现横向溢出，页头语言入口均可见，交互内容未报告加载错误。

实际操作确认：

- 普通首页记住中文选择，`?lang=en` 明确打开英文，旧 `/#AS-001` 到达对应中文案例。
- 搜索“金线”在两种语言均返回 AS-001 和 AS-002，切换保留查询；词典搜索“木刻”切换后仍只显示 term-39。
- 创作页切换参考后，输入中英混合目标、保留项和避免项；关闭建议避免项、取消动作保留、取消线条特征、选择不指定配色。切换语言及前进后退后，这些设置全部保留。
- 提示词尚未主动选择输出语言时跟随页面；主动选择后，页面切换不改变输出语言。自由输入保持原文。
- AS-007 图片对比滑块设为 1%，切换后仍为 1%，无障碍值说明改为对应语言。
- 中文未知路径在本地显示中文 404，样式正确加载；关闭 JavaScript 的兜底通过静态 HTML 内容及语言链接校验，未声称执行浏览器禁用脚本模式。
