怎样组合搜索词？

从“风格或艺术家 + portrait / figure drawing / character design / sketchbook + 视觉效果”开始。一次只改变一个词，比较结果。搜索结果的标题不能代替作品出处。

例如：Art Nouveau portrait linework、Mary Blair character design color。Mid-century 在这里指 20 世纪中叶。

从观察开始，把风格说清楚。
